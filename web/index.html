WHAT THIS IS

Three live demos that compose multi-agent AI swarms — agents that plan together, disagree, and rewrite each other to improve. Each demo is a self-contained HTML application backed by your choice of provider.

DEMO MODE needs no API key — pre-recorded transcripts play back inside each demo. Free.

LIVE MODE calls real models — Claude (via Claude Code, Anthropic direct, or OpenRouter), free OpenRouter, or Ollama (local). See the docs below for setup.
